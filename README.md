# GymRat 
 
GymRat is a mobile workout tracking app that helps users plan, log, and track their fitness progress over time.
 
## Features
 
- Log workouts, sets, reps, and weight
- Plan and schedule workout routines
- Track progress and personal records over time
- User accounts and profiles
- Cross-platform mobile experience
## Tech Stack
 
**Backend**
- Django (REST API)
- PostgreSQL (via Supabase)
- Django REST Framework
**Frontend**
- React Native (mobile)
**Infrastructure**
- Supabase (database + optional auth/storage)
